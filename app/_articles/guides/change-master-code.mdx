## Treat the Master Code Like an Admin Password

The master code, programming code, or admin PIN is more sensitive than a normal door code. On many smart locks it can add users, delete users, change schedules, adjust settings, and sometimes disable protections. A guest PIN opens the door. A master code can change who is allowed to open the door.

Change it immediately after installation, after inheriting a lock, after a roommate or employee leaves, after a contractor was given too much access, or anytime the code may have appeared in a message, note, or shared document. Do not give the master code to ordinary guests or service providers. Give them normal user codes instead.

Brand language varies. Yale may call it a master PIN. Schlage often uses programming code. Kwikset may separate master user and user codes. August retrofit locks usually rely more on app ownership than a keypad master code. Before changing anything, identify the actual administrator credential for your model.

## Prepare Before You Rotate It

Make sure you have a fallback entry method before editing admin access. Keep the physical key with you, confirm app owner access works, or have another administrator present. If the lock supports emergency power, know how to use it. Replace weak batteries before changing codes because some locks fail to save settings reliably when power is low.

Choose the new code before opening the settings screen. Use a random 6 to 8 digit code if the lock supports it. Avoid birthdays, addresses, repeated digits, phone endings, and obvious patterns. Store the code in a password manager or secure property record with the lock model, door name, and recovery notes.

If this is a rental, office, or shared household, plan the timing. A code rotation should remove old authority without surprising current authorized users. The right moment is when you can immediately test the new code and update any people who genuinely need administrator access.

## Change It in the App or at the Keypad

For app-connected locks, open the correct door in the app and look under settings, access, users, keypad, or owner controls. Enter the current administrator code if requested, set the new code, save, and wait for the lock to confirm that the change has synced. Then test the new code on the physical keypad with the door open.

For keypad-only programming, use the printed manual or current manufacturer support page for the exact button sequence. The general pattern is old programming code, program command, new code, confirmation. Enter slowly and wait for the lock's confirmation beeps or lights before testing.

Do not stop at "saved" in the app. The only proof that matters is the door. Test the new master or programming code, then confirm the old one no longer works. Keep the door open during testing so a typo does not become a lockout.

## Clean the User List at the Same Time

A master-code change is the right moment to review every user. Delete former guests, old contractors, duplicate test codes, unused app invites, and anyone whose access no longer has a clear reason. Rotating the administrator credential while leaving stale user codes in place only solves half the problem.

Most household members do not need the master code. Give them individual user codes so access logs remain useful and their access can be removed without another admin rotation. For rentals or small offices, never reuse one master code across multiple properties. If one person learns it, every door using that code is exposed.

## If the Change Does Not Stick

If the new code does not work, wait for sync and try again slowly. If the old code still works, the update probably did not reach the lock. Check battery level, hub or Wi-Fi status, and whether the app shows a pending update. Then repeat the change with the door open.

If neither the old nor new code works, use the app owner account or physical key before attempting a reset. A factory reset should be the last resort because it can remove users, schedules, calibration, and integrations. If you must reset, set a new master code before re-adding regular users.

## How Often to Change It

For a normal home, rotate the master code when risk changes, not on an empty calendar. For rentals, offices, and shared staff access, review administrator access at least quarterly and whenever people leave. The best security improvement is not constant rotation; it is keeping the master code private, issuing unique user codes, and deleting old access quickly.
