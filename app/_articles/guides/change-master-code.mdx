## Quick Answer

Change the smart lock master code from the app or programming menu, then test the new code at the keypad before you close the door for good. Use a random 6 to 8 digit code, store it in a password manager, and remove any old notes or shared messages that contain the previous code.

Change it immediately after installation, after anyone with admin access leaves, after a breakup or roommate change, after a contractor or guest was given too much access, or anytime you suspect the code was exposed. A master code is not a guest PIN. Treat it like the administrator password for the door.

## What the Master Code Controls

On many locks, the master code or programming code can add users, delete users, change settings, and sometimes disable access schedules. That makes it more sensitive than a normal unlock code. A guest code opens the door; the master code can change who is allowed to open the door.

Brand terminology varies. Yale often says master PIN or master code. Schlage commonly uses programming code. Kwikset may separate master user and user codes. August does not usually use a traditional keypad master code for the interior retrofit lock, but the app owner role serves the same administrative purpose.

Before changing anything, confirm which credential is the administrator credential for your exact model. Do not rotate a normal user PIN and assume the lock is secure if the old programming code still exists.

## Before You Change It

Make sure you have a backup entry method first: physical key, app owner access, another administrator, or a working emergency power method if the lock supports 9V jump-start. Replace weak batteries before changing the code because some locks fail to save settings reliably when the battery is low.

Choose the new code before you open the programming screen. Avoid birthdays, addresses, repeated digits, phone numbers, and obvious patterns. A password manager can generate a random numeric code and store it with the lock model, location, and recovery notes.

If this is a rental, office, or shared household, schedule the change when you can immediately update the people who should still have access. The goal is to remove old authority without locking out current authorized users.

## Change the Code in the App

Most app-connected locks follow this pattern:

1. Open the lock app and select the correct door.
2. Open `Settings`, `Access`, `Users`, or `Keypad`.
3. Find `Master Code`, `Programming Code`, `Admin Code`, or owner settings.
4. Enter the current administrator code if requested.
5. Enter the new random code.
6. Save and wait for the app to confirm sync.
7. Test the new code on the keypad.
8. Confirm the old code no longer works.

Do not stop at the app confirmation screen. The only useful proof is at the door. Test while the door is open so a mistake does not lock you outside.

## Change the Code at the Keypad

Some locks allow code changes without the app. You usually enter the existing programming code, press a program or gear button, choose the change-code command, then enter the new code twice. The exact sequence is model-specific, so use the printed manual or the current manufacturer support page for the final button order.

Keypad programming is useful when the phone app is unavailable, but it is also where mistakes happen. Enter slowly, wait for the lock's confirmation beeps or lights, and test with the door open.

## Pick a Strong Numeric Code

A good master code is random and long enough for the model. Six digits is a reasonable minimum; eight is better if the lock supports it. Do not use `123456`, `000000`, `111111`, the street number, the last four digits of a phone number, or a date that someone can guess.

Do not reuse the same master code across multiple properties. If one cleaner, contractor, or former staff member learns it, every door with that shared code becomes exposed. For portfolios, store each code under the property address and door name.

## After the Change

After the master code is changed, review the user list. Delete former guests, old contractors, test codes, duplicate codes, and anyone who no longer needs access. A master-code rotation is the right moment to clean the entire credential list because you are already checking the door's security state.

Then update only the people who need the new administrator credential. Most household members and guests do not need it. Give them normal user codes instead. If you must send the master code, use a secure channel and delete the message afterward.

## Troubleshooting

If the new code does not work, wait a minute for sync and try again slowly. If the old code still works, the change may not have saved. Repeat the process with fresh batteries and keep the door open while testing.

If neither old nor new code works, use the app owner account or physical key. A factory reset should be the last resort because it can remove all users, schedules, and integrations. If you do reset, set a new master code immediately before re-adding user access.

## Rotation Schedule

For a normal home, rotate the master code when people or risk changes, not on a meaningless calendar. For rentals, offices, and shared staff access, review it at least quarterly. High-turnover properties should separate daily access from administrator access so the master code rarely needs to be shared at all.

The best security improvement is not constant code changing. It is keeping the administrator code private, using unique user codes for everyone else, and deleting access the same day it is no longer needed.
