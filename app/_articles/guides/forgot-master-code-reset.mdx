## Quick Answer

If you forgot the smart lock master code, do not factory reset first. Start with the least destructive recovery path: check the app for admin access, change the code from the app if allowed, use the physical backup key to get inside, and only then consider a factory reset. A factory reset can erase user codes, schedules, hub pairing, fingerprints, and automation settings.

If you still have app owner access, the fix is usually simple: open the lock app, find the master code or programming code settings, create a new code, save, and test it at the keypad with the door open. If you do not have app access or a key, you may need the interior reset button or professional help.

## First: Separate Lockout From Forgotten Code

Forgetting the master code is not always the same as being locked out. If the door is open or you can enter with a user PIN, app unlock, fingerprint, or physical key, you have time to recover cleanly. If you are outside with no working credential, solve entry first and settings second.

Use any legitimate backup method available: app owner unlock, physical key, another admin user, emergency 9V power if the keypad is dead, or a locksmith. Once you are inside, leave the door open while changing settings so a mistake does not create another lockout.

## Check the App

Many smart lock apps either show the master code after authentication or let the owner replace it. Look under `Settings`, `Users`, `Keypad`, `Access Codes`, `Master Code`, or `Programming Code`. The app may require Face ID, Touch ID, password confirmation, or account login before showing sensitive credentials.

If the app lets you change but not view the code, set a new random 6 to 8 digit code and save it. Wait for sync, then test the new code on the keypad. Also test that the old forgotten code no longer works if you later recover it from notes.

If the lock is offline, app changes may not reach the hardware. Wake the keypad, bring the phone close to Bluetooth locks, check the hub, or restore Wi-Fi before assuming the app recovery failed.

## Use the Backup Key

Most full-replacement deadbolt locks include a mechanical keyway. The keyhole may be visible, hidden under a cap, or placed below the keypad. Use the key to enter, then recover the master code from the app or reset the code from the interior side.

If you lost the backup key but know the lock brand and key code, the manufacturer or a locksmith may be able to cut a replacement. If the door is urgent, a locksmith is usually safer than drilling or forcing the smart lock body.

Interior retrofit locks such as some August models depend on the original deadbolt cylinder outside, so the old house key may still be the mechanical backup.

## Reset Only When Needed

Factory reset is appropriate when you inherited a lock with unknown admin access, lost the app owner account, cannot recover the programming code, or need to remove every old credential after a security event. It is not the right first step for a single forgotten PIN if the app still works.

Most factory resets require access to the interior side of the lock. You remove the battery cover, hold a program or reset button, and keep holding through a beep or light pattern. Some models require removing and reinserting a battery while holding the button. The exact sequence is brand-specific, so check the current manual for your model before pressing buttons.

After reset, set the new master code immediately. Then re-pair the lock to the app or hub, re-add only current users, test backup entry, and recreate any schedules you still need.

## Brand Notes

Yale Assure models usually use the Yale Access app or an interior programming button flow. Schlage Encode and Connect use a programming code, often printed on the original label or manual. Kwikset SmartCode locks use a program button and may require a door-handing step after reset. August primarily uses app owner access rather than a traditional keypad master code unless a keypad is paired.

For Z-Wave and Zigbee locks, remember that the hub may still contain stale user-code data. After a reset, exclude or remove the old device from the hub before pairing it again. Otherwise you can end up with duplicate devices or codes that appear in the hub but do not exist on the lock.

## After You Regain Access

Store the new master code in a password manager with the lock brand, model, door name, and backup-key location. Do not keep it in a shared text thread or on paper near the door.

Review the user list before you finish. Delete unknown codes, old guests, contractors, duplicate test codes, and app invites you no longer recognize. If you reset because you inherited or bought the property, treat the lock as untrusted until every credential has been recreated by you.

## Prevent the Next Lockout

Keep at least two recovery paths: one digital and one physical. For example, app owner access plus a physical key stored securely, or a trusted second admin plus a key. Replace weak batteries before they are critical, and test the backup key once after installation so you know it actually turns the cylinder.

If this is a rental or commercial door, document the recovery process. The person who knows how to reset the lock may not be the person standing at the door during an emergency.
