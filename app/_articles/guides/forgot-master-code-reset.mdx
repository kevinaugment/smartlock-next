## Recover Access Before Resetting

Forgetting the master code does not always mean the lock must be reset. If you can still enter with the app, a user PIN, fingerprint, or physical key, recover the administrator credential from inside the normal system first. Factory reset is useful when ownership is unknown or admin access is gone, but it can erase users, schedules, fingerprints, hub pairing, and automations.

Separate two problems: getting through the door and regaining admin control. If you are outside with no working credential, use a legitimate entry method first: app owner unlock, physical key, another administrator, emergency power for a dead keypad, or a locksmith. Once inside, leave the door open while changing settings.

## Check the App and Owner Account

Many smart lock apps let the owner view or replace the master code after account authentication. Look under settings, users, keypad, access codes, master code, programming code, or owner controls. The app may require Face ID, Touch ID, password confirmation, or a current login before showing sensitive information.

If the app lets you change but not view the code, create a new random 6 to 8 digit code, save it, and wait for sync. Test the new code at the keypad with the door open. If the old code later turns up in notes, confirm it no longer works.

If the lock is offline, the app may not be able to push the new code. Wake the keypad, stand near Bluetooth locks, check the hub, or restore Wi-Fi before assuming app recovery failed.

## Use the Mechanical Backup

Most full-replacement deadbolt locks include a keyway, sometimes hidden under a cap or below the keypad. Use the key to get inside, then change the master code from the app or interior programming menu. Interior retrofit locks usually keep the original exterior cylinder, so the old house key may still be the backup.

If the key is lost but the lock brand and key code are known, the manufacturer or a locksmith may be able to help. For urgent access, a locksmith is usually safer than drilling, prying, or damaging the smart lock body.

## Reset Only When Recovery Fails

Factory reset is appropriate when you inherited a lock with unknown users, lost the app owner account, cannot recover the programming code, or need to clear every credential after a security issue. Most resets require access to the interior side of the lock and a model-specific button sequence.

Check the current manual for the exact model. The pattern is often: remove the battery cover, hold a program or reset button, restore power if required, and keep holding until a beep or light pattern confirms reset. Afterward, set a new master code immediately, re-pair the app or hub, add only current users, and test the physical backup.

For Z-Wave and Zigbee locks, remove or exclude the old device from the hub before pairing again. Otherwise the hub may show stale devices or codes that no longer exist on the lock.

## Prevent the Next Lockout

Store the new master code in a password manager with the lock brand, model, door name, and backup-key location. Do not keep it in a shared text thread or a loose note near the door.

Keep at least two recovery paths: one digital and one physical. For rentals and businesses, document who can recover admin access, where backup keys are controlled, and what should be logged after an emergency reset.
