## Quick Answer

To add a new smart lock user code, open the lock app, choose the correct door, add a user or access code, enter a clear name, choose a unique PIN, set the access schedule, save, wait for sync, and test the code on the physical keypad before sharing it.

The testing step matters. A code can look saved in the app while it is still waiting to sync to the lock. For guests, cleaners, and contractors, do not send the code until you know the keypad accepts it.

## Decide What Kind of Access This User Needs

Do not give everyone permanent access. A family member or long-term tenant may need an always-active code. A guest, cleaner, contractor, dog walker, or delivery helper usually needs a temporary or recurring schedule.

Use the narrowest access that still works:

| User type | Better access type | Why |
|---|---|---|
| Family or primary resident | Permanent code | Ongoing access is expected |
| Airbnb or house guest | Temporary code | Expires after the stay |
| Cleaner | Recurring schedule | Works only on service days |
| Contractor | One-day temporary code | Ends when the job ends |
| Emergency contact | Permanent or sealed backup code | Needs availability during failures |

If the lock supports app keys, decide whether the user needs app control or only keypad entry. App users may see status, logs, or settings depending on the role. A PIN is often enough.

## Pick a Good PIN

Use a unique code for each person. Shared codes are convenient until you need to know who entered or whose access should be removed. A unique code makes access logs useful and lets you revoke one person without changing everyone else.

Use the longest practical length your lock supports, usually 6 to 8 digits. Avoid `1234`, `0000`, birthdays, street numbers, phone endings, and repeated patterns. For rentals, avoid reusing the same guest code across bookings.

If you manage several doors, store codes in a password manager or property-management system. Do not keep them in loose notes or old message threads.

## Add the Code in the App

Most apps follow this general pattern:

1. Open the smart lock app.
2. Select the correct lock if you manage more than one.
3. Open `Users`, `Access`, `Access Codes`, `Keypad Codes`, or `Guests`.
4. Choose `Add`, `Add user`, or `Create code`.
5. Enter the user's name and PIN.
6. Choose permanent, temporary, recurring, or one-time access if available.
7. Save and wait for the app to confirm the lock has synced.

Name users in a way that will still make sense later. "Cleaner - Tue morning" or "Guest - Lee - May 12-15" is better than "Guest 3." For rentals, include the booking or checkout date in the name.

## Set the Schedule

For permanent users, choose always active only when the person should retain access until you manually remove it. For temporary users, set both a start and end time. For recurring users, set the days and hours carefully.

Avoid midnight confusion. If a code should work through checkout day, set the end time to 11:59 PM on that day or 12:00 AM on the following day, depending on the app's wording. Setting 12:00 AM on the checkout date can expire the code at the beginning of that day.

Use a reasonable buffer. A guest code can start 1 to 2 hours before check-in. A contractor code can start 15 to 30 minutes before the appointment. Too-tight schedules create unnecessary support calls.

## Wait for Sync

Wi-Fi locks may update quickly. Bluetooth, Z-Wave, and Zigbee locks may take longer, especially if the hub is busy or the lock is sleeping. Wait for a clear synced, saved, or success state before testing.

If the app hangs on sending, wake the keypad, bring the phone closer, check the hub, or send a lock/unlock command to force communication. If the lock is offline, fix connectivity before creating the code again.

Do not create the same user repeatedly while waiting. Duplicate entries make later cleanup harder and can hit the lock's code limit.

## Test Before Sharing

Go to the door and enter the new PIN. Press the final lock, checkmark, or pound button if your model requires it. The lock should unlock cleanly without repeated attempts.

If the code fails, wait a few minutes and try again. Then verify the code in the app, check whether the schedule has already started, and confirm the lock is online. If it still fails, delete the code and create a fresh one.

For remote properties, use the app's status and audit log if physical testing is impossible. If the code is for a same-day arrival, create a backup code as well and keep it ready until the first entry succeeds.

## Brand Notes

Yale apps usually list keypad codes under the lock or user profile. Schlage Home uses access codes. Kwikset uses users and may limit code counts by model. August uses guest access or eKeys, and keypad PINs depend on whether a keypad accessory is installed. Hub-managed Z-Wave and Zigbee locks may require setting a code slot in the hub interface.

The labels differ, but the same rule applies: create, sync, test, then share.

## After the User No Longer Needs Access

Adding a code should include a plan for removing it. Temporary codes should expire automatically, but you should still review the list. Permanent codes for former roommates, employees, contractors, and guests should be deleted immediately.

For rentals and small businesses, schedule a regular access audit. The user list should be short enough that every entry has a clear owner and purpose.
