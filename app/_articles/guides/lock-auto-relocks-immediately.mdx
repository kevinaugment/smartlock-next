## Treat Instant Relock as a Rule Conflict First

A smart lock that relocks immediately after unlocking is usually following a rule somewhere. The rule may be the lock's native auto-lock timer, a door-sensor-based routine, a night or away mode, or a smart-home automation that was created months ago and forgotten. The first fix is not a factory reset. It is finding which rule is issuing the lock command.

Temporarily turn off auto-lock in the lock app and unlock the door. If it now stays unlocked, the native timer or sensor rule is the likely cause. If it still relocks, look outside the lock app: HomeKit, Alexa, Google Home, SmartThings, Home Assistant, a security panel, or a property-management integration.

## Match the Timing to the Cause

The delay tells you where to look. A relock after 5 to 30 seconds usually means the timer is too short. A relock as soon as the door closes points to a door sensor rule. A relock only at night, when everyone leaves, or after an alarm mode changes is usually a platform routine.

Test more than one unlock method. Use the keypad, app, thumb turn, and physical key if available. If only app unlock triggers the problem, a platform automation may be reacting to app state. If every method relocks, native auto-lock or a door sensor is more likely.

## Set a Delay That Fits Real Use

Set the native auto-lock delay to at least 3 to 5 minutes as a baseline. For families, deliveries, mobility needs, or doors used while carrying items, 7 to 10 minutes may be more realistic. A 30-second setting can look secure in the app and still be unusable in daily life.

After changing the delay, test with the door open and closed. Confirm that the timer restarts after a second unlock, and that the lock does not throw the bolt while the door is still open.

## Check Sensor and Platform Rules

Watch the door state in the app while opening and closing the door. If the sensor reports closed too early, the lock may relock before someone is through the doorway. Recalibrate the sensor, realign the magnet, and replace a separate sensor battery if needed. If the sensor remains unreliable, use a timer-only rule until it is fixed.

Then audit connected platforms for routines triggered by unlock, door closed, night mode, away mode, alarm armed, or "secure house." Keep one automatic locking rule, not several. If a smart-home platform controls relocking, either disable native auto-lock or make the native timer longer so it acts only as a fallback.

## Use Overrides Deliberately

During move-in, maintenance, parties, or repeated trips to the car, turn auto-lock off or use passage mode if your model supports it. Set a reminder to turn it back on. Privacy mode and passage mode are not the same thing on many locks, so confirm which setting blocks access and which setting keeps the door unlocked.

If instant relock persists after native settings, sensor status, and automations are cleaned up, reset only the auto-lock configuration before considering a full factory reset. Document active users and backup access before any reset.
