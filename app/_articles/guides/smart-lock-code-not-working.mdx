## Quick Answer

When a smart lock PIN does not work, first confirm the code in the app, check whether it is active or expired, wait for sync if it was just created, and enter it slowly on the keypad. If other codes work, the issue is probably that specific user code or schedule. If no codes work, check battery level, keypad response, lockout mode, and connectivity.

Do not immediately factory reset the lock. Most PIN failures are caused by timing, sync, expiration, entry format, or one bad user record.

## Check Whether the Code Actually Exists

Open the lock app and look at the user's code, not just the user's name. It is common to remember an old code, mistype a new one, or send a guest the wrong digits.

If the app shows the code as pending, sending, or not synced, wait and wake the lock by pressing the keypad or sending a status command from the app. A new code can appear in the app before the lock has received it.

If the code does not appear at all, recreate it with a new PIN and test before sharing.

## Check the Schedule

Temporary and recurring codes fail when the current time is outside the allowed window. Confirm the start date, end date, days of week, timezone, and active hours.

Midnight is a common trap. If a code should work through March 20, do not set it to expire at 12:00 AM on March 20 unless the app clearly means the end of the day. Use 11:59 PM on March 20 or 12:00 AM on March 21.

If the lock's internal clock or hub timezone is wrong, scheduled codes can fail even when the app looks correct. Sync the lock, hub, or account timezone if the schedule seems off by hours.

## Enter the Code Slowly

Keypads can reject correct codes when digits are entered too quickly, missed, doubled, or followed by the wrong final button. Press each digit firmly and wait for the lock's feedback. Some models require pressing a checkmark, lock button, or pound key after the PIN.

Clean the keypad if one digit is hard to press or does not beep. On worn keypads, avoid codes that rely on a failing digit until the keypad is repaired.

If there have been several failed attempts, wait for the lockout timer to expire. Many locks temporarily disable the keypad after repeated wrong codes.

## Compare With Another Code

Try a code you know works. If another code opens the door, the keypad and motor are probably fine. Focus on the failing user's PIN, schedule, sync status, or permissions.

If no code works, use app unlock, fingerprint, physical key, or emergency power if available. Then check batteries and keypad hardware from the inside.

## Replace Weak Batteries

Low batteries can make a keypad behave strangely before the lock is fully dead. The backlight may be dim, beeps may lag, or the motor may start and stop after accepting a code.

Replace all batteries with fresh cells from the same pack. Do not mix old and new batteries. If the lock has 9V emergency terminals, use them only long enough to enter and replace the internal batteries.

## Fix Sync and Connectivity

For Wi-Fi locks, confirm the lock is online. For Bluetooth locks, stand near the door. For Z-Wave and Zigbee locks, confirm the hub is online and close enough to reach the lock.

If the lock was offline when you created the code, delete the user and create it again after the lock reconnects. Avoid repeatedly editing the same stuck code; a clean new user record is easier to verify.

## Check User Limits and Duplicates

Some locks have limited code slots. If the lock is full, a new code may fail to save, fail to sync, or silently overwrite a slot depending on the system. Delete old guests, test codes, and unused service-provider codes before adding more.

Also avoid duplicate PINs. Some systems reject them; others allow confusing duplicates that make logs useless.

## When It Is a Hardware Issue

Suspect keypad hardware if a specific number never responds, the keypad registers double presses, moisture is visible, or all codes fail while app unlock still works. Dry the keypad, clean it gently, and contact the manufacturer if the problem continues.

Suspect the motor or alignment if the code is accepted but the bolt does not move fully. That is no longer a PIN problem; see the partial-lock and motor-noise guides.
