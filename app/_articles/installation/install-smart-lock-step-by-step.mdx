A smart lock installation is mostly a deadbolt installation with one extra requirement: the motor must be able to move the bolt without fighting the door. Pairing the app is usually the easy part. The real work is measuring correctly, mounting without pinching cables, and testing alignment before final tightening.

Most retrofit smart locks fit standard residential deadbolt prep. If the existing deadbolt moves smoothly and the door has standard bore holes, installation may take less than an hour. If the door is misaligned, painted shut around the latch, unusually thick, or missing standard holes, solve that before opening the smart lock box.

Use the [Door Compatibility Checker](/calculators/compatibility) before buying and [Installation Time Estimator](/calculators/installation-time) if you are planning around tenants, guests, or a workday.

## Before You Remove The Old Lock

Measure door thickness, backset, and bore size. Check whether the lock supports your door thickness and whether the latch can match the existing backset. Take a photo of the old lock from both sides before removing it, especially if you may need to reinstall it.

Open the door and test the old deadbolt. If it does not extend smoothly, the smart lock will inherit the same problem. Tighten hinges, adjust the strike plate, or clear paint buildup before installing the new lock.

Gather a Phillips screwdriver, fresh batteries, the lock manual, and your phone. Avoid using a drill to tighten mounting screws unless the manufacturer explicitly allows it; over-tightening can distort the lock body and cause binding.

## Remove The Existing Deadbolt

Keep the door open while you work. Remove the interior screws, separate the interior and exterior lock assemblies, then remove the latch from the door edge. Keep the old hardware in a bag until the new lock is fully tested.

Do not remove or replace the strike plate immediately unless the new lock requires it. The existing strike gives you a useful baseline for alignment. You can adjust or replace it after the new latch is in place.

## Install The Latch And Exterior Assembly

Insert the new latch in the correct orientation and make sure it sits flush with the door edge. The bolt should extend and retract by hand before the keypad or exterior assembly is attached. If it rubs inside the bore, fix that now.

Mount the exterior keypad or lock body while routing any cable carefully through the door. The cable should not be pinched, folded sharply, or trapped under a screw. Hold the exterior assembly straight while attaching the interior mounting plate.

Start screws by hand and tighten gradually. If the thumb turn becomes stiff as you tighten, loosen slightly and realign the assembly. A smart lock should not need force to operate.

## Install The Interior Assembly

Connect the cable if the lock uses one, then attach the interior assembly according to the manual. Insert fresh batteries only after the mechanical parts are seated unless the manufacturer gives a different order.

Before pairing the app, test the lock manually with the door open. Turn the thumb turn several times and listen for scraping or grinding. If manual movement is not clean, app setup will not fix it.

## Test With Door Open And Closed

With the door open, test manual locking, keypad locking, and app locking if available. Then close the door gently and repeat. The deadbolt should enter the strike without pushing, lifting, or pulling the door.

If the bolt hits the strike, adjust the strike plate. If the motor strains, check alignment and mounting screw tension. If the app reports the wrong status, calibrate the lock after the mechanics are correct.

Use [Test Smart Lock After Installation](/articles/installation/test-smart-lock-after-install) for the final verification pass and [Calibrate Smart Lock](/articles/installation/calibrate-smart-lock) if the lock needs to relearn positions.

## Pair The App And Add Codes

Once the lock moves smoothly, pair it with the app or hub. Keep your phone near the lock, follow the manufacturer's pairing sequence, and name the door clearly. For Zigbee, Z-Wave, Thread, Matter, or HomeKit locks, make sure the hub or border router is online before pairing.

Create a master/admin code first, then create normal user codes. Do not reuse a default code. For rentals or shared properties, give each person or role a unique code so access can be removed cleanly later.

## Final Checks

Test the physical key if the lock has one, check battery level, confirm app status is accurate, and verify auto-lock settings before relying on the door. Keep the manual and reset code in a secure place.

The installation is finished only when the lock works smoothly with the door open and closed, every access method has been tested, and backup access is available. If any part feels inconsistent, fix it before daily use.
