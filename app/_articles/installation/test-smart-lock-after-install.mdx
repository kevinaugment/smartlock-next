Do not consider a smart lock installation finished when the app says setup is complete. The lock still has to prove that the deadbolt moves cleanly, the keypad works, the app reports the correct state, the backup key opens the door, and the lock can repeat normal use without jamming.

Most post-installation problems come from mechanical fit, not software. A deadbolt that barely scrapes the strike plate may pass one app test and then fail at night when the door shifts, the weather seal pushes back, or the batteries are weaker. Testing catches those problems while the tools are still out.

Use this guide after [Install Smart Lock Step by Step](/articles/installation/install-smart-lock-step-by-step), and keep [Door Alignment Guide](/articles/guides/door-alignment-guide) nearby if the bolt does not move smoothly.

## The Minimum Test

Start with the door open. Lock and unlock manually from the inside several times. The thumb turn should move smoothly, without grinding, scraping, or springing back. Then close the door and repeat the same test. If the closed-door movement feels harder, fix alignment before testing electronics.

Next, test each normal access method:

1. Lock and unlock from the app.
2. Unlock with the keypad code.
3. Lock and unlock with the physical key if the lock has one.
4. Confirm the app status changes correctly after manual operation.
5. Check battery level and signal status in the app or hub.

If any of these fail, stop and fix the issue before adding users, guests, tenants, or automations.

## Alignment Test

Alignment is the most important test because it affects reliability, battery life, and security. With the door open, extend the deadbolt and look at the bolt position. Retract it, close the door slowly, and watch whether the bolt lines up with the strike opening.

The bolt should enter the strike without pushing, lifting, pulling, or slamming the door. There should be no grinding sound and no visible rub mark on the bolt. If the lock motor sounds strained or reverses direction, the door is not ready.

Common fixes include tightening hinges, adjusting the strike plate, deepening the strike pocket, correcting weather-strip pressure, and recalibrating the lock after the mechanical fit is smooth.

## Keypad And Code Test

Create at least two user codes and test each one. Confirm that the keypad wakes reliably, accepts the code, unlocks the door, and gives clear feedback. If the lock supports temporary codes, create one and confirm the start and expiration behavior.

Then test wrong-code behavior. Enter an incorrect code a few times and confirm the lock responds as expected. For exterior doors, rentals, and businesses, failed-attempt lockout and alerts are useful security controls.

For code management, pair this test with [How to Add User Code](/articles/guides/how-to-add-user-code), [Change Master Code](/articles/guides/change-master-code), and [Share Access Securely](/articles/security/share-access-securely).

## App, Hub, And Network Test

Run several app commands from normal use locations, not while standing next to the lock with the door open. Confirm that commands complete, status updates match the real door state, and the lock does not repeatedly show offline.

For Wi-Fi locks, check signal at the door and confirm the lock uses the intended 2.4 GHz network. For Zigbee, Z-Wave, or Thread locks, check that the hub, border router, or repeater path is stable. Weak signal can cause slow response, failed commands, and battery drain.

If the lock has trouble staying online, use [Improve Connection Stability](/articles/protocols/improve-connection-stability) and [Smart Lock Keeps Going Offline](/articles/protocols/smart-lock-keeps-going-offline).

## Auto-Lock And Door Sensor Test

If auto-lock is enabled, test it with the door closed and with the normal timeout. Confirm that the door actually locks, not just that the app says it locked. If the lock includes a door position sensor, open and close the door several times and confirm the app reports the state correctly.

Be careful with short auto-lock timers during setup. A timer that is convenient in daily use can be annoying while moving furniture, cleaning, or testing the door. Set the final timer after you understand the normal traffic pattern.

## Repeat-Cycle Test

After the basic tests pass, run repeated cycles. You do not need a theatrical stress test, but you should operate the lock enough times to expose obvious problems. A practical test is 10 manual cycles, 10 keypad cycles, and 10 app or hub cycles, with at least some of those done while the door is closed.

There should be no jams, timeouts, repeated retries, or wrong status reports. One failure during a new installation is not something to ignore. It is usually a clue that alignment, calibration, battery seating, or signal quality still needs attention.

## Backup Access Test

Test the backup before you need it. If there is a physical key, insert it and unlock the door. If there is an emergency battery terminal, confirm where it is and what battery type it requires. If a landlord, host, or business uses a backup lockbox or local contact, make sure the process is documented.

For rentals and commercial doors, backup access is part of the installation, not an optional extra. Use the [Emergency Backup Planner](/calculators/emergency-backup) if someone other than you may depend on the door.

## Final Pass Criteria

The installation is ready for daily use when the deadbolt moves smoothly with the door open and closed, every access method works, status reporting is accurate, signal and battery status are healthy, auto-lock behaves correctly, and backup access has been tested.

If the lock fails any of those checks, fix the cause before relying on it. A smart lock that only works during setup is not installed; it is just attached to the door.
