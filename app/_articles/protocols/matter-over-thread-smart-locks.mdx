## Quick Answer

Matter is the interoperability standard. Thread is the low-power mesh network a lock may use underneath Matter. A Matter over Thread smart lock needs a Matter controller and a Thread border router, but it can offer better battery behavior than a Wi-Fi lock.

Start with the [Protocol Selection Wizard](/calculators/protocol-wizard) if you are unsure whether your home needs Matter, Thread, Wi-Fi, Z-Wave, or Zigbee.

## Matter vs Thread

| Term | What it means | Smart lock impact |
|---|---|---|
| Matter | Application standard for cross-platform device control | Helps Apple, Google, Alexa, SmartThings, and other platforms talk to the lock |
| Thread | Low-power IP mesh radio network | Helps battery devices communicate without staying on Wi-Fi |
| Matter over Thread | Matter commands carried over a Thread network | Usually better for battery locks than direct Wi-Fi |
| Border router | Bridge between Thread and your IP network | Required for Thread devices to join the broader smart home |

## Controller and Border Router Checklist

Before buying, confirm these four items:

1. Your platform has a Matter controller.
2. Your home has a Thread border router where the lock can reach it.
3. The exact lock model supports Matter over Thread, not only Matter over Wi-Fi.
4. The features you need are exposed through your chosen platform.

Apple HomePod mini, newer Apple TV models, selected Google/Nest devices, and some SmartThings hubs can act as border routers, but support varies by model and firmware.

## Battery and Range Reality

Thread is designed for low-power devices, so it is usually a better fit than direct Wi-Fi for locks that need long battery life. It still uses 2.4 GHz, so distance, walls, metal doors, and Wi-Fi congestion can affect performance.

Use the [Battery Life Calculator](/calculators/battery-life) and [Signal Strength Calculator](/calculators/signal-strength) before blaming the lock brand.

## Buyer Mistakes

- Buying a "Matter" lock and assuming it is Thread.
- Forgetting that Thread still needs a border router.
- Expecting every advanced lock feature to appear in every Matter app.
- Using Matter as a shortcut around door compatibility checks.
- Choosing a new standard for a rental fleet before support workflows are proven.

## Best Fit Scenarios

| Buyer | Matter over Thread fit |
|---|---|
| Apple-first homeowner | Strong, especially if Home Key is also supported |
| Mixed-platform household | Strong if all controllers are current |
| Airbnb host | Useful, but guest-code workflow matters more |
| Landlord portfolio | Pilot first; maintenance tooling may matter more |
| Enterprise team | Consider only after audit, identity, and integration needs are defined |
