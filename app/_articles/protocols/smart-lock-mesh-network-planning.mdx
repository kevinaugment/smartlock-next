## Plan the Path Before Installing the Lock

A smart lock mesh works only when the hub, powered repeaters, and door locations are planned together. Battery locks usually do not repeat traffic, so every exterior door needs a reliable route to a powered node, hub, border router, or coordinator. Guessing from a desk test is how fleets end up with slow commands and short battery life.

Start with the [Mesh Network Planner](/calculators/mesh-planner), then validate weak links with the [Signal Strength Calculator](/calculators/signal-strength) or [RF Coverage Planner](/calculators/rf-coverage).

## Repeaters Need to Be on the Route

Place repeaters between the hub and the lock, not behind the lock or in random outlets. For an exterior door, the best repeater may be an interior plug near the entry, a powered module in the next room, or a hub moved closer to the door path. After adding repeaters, allow the mesh to rebuild if the platform requires it, then test status and commands several times.

Heavy-use doors deserve stronger signal than rarely used storage doors. Retries wake the lock, delay commands, and drain batteries. If batteries die faster than expected, check signal and door alignment before blaming the lock brand.

## Protocols Behave Differently

Z-Wave often performs well through some walls because it uses sub-GHz frequencies. Zigbee and Thread use 2.4 GHz, so Wi-Fi congestion, appliances, concrete, and metal doors can matter more. Thread has a Matter-forward path, while Zigbee has a mature hub and repeater ecosystem.

The right protocol depends on the building. A generic range number is less useful than testing the actual path from controller to door.

## Rental and Multifamily Notes

Do not standardize a rental or multifamily fleet from one easy door. Pilot units on different floors, corridor ends, elevator-adjacent doors, metal fire doors, and remote buildings. Track command latency, battery life, missed status updates, and support tickets before scaling.

For rentals, controller ownership is part of the network plan. A tenant-owned router or hub can make a technically good mesh impossible to support.
