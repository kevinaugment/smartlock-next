## Quick Answer

A smart lock mesh network works best when the hub, powered repeaters, and lock locations are planned before installation. Battery locks usually do not repeat traffic, so every exterior door should have a reliable powered node or hub path nearby.

Start with the [Mesh Network Planner](/calculators/mesh-planner), then validate weak links with the [Signal Strength Calculator](/calculators/signal-strength).

## Mesh Planning Table

| Planning item | Why it matters | What to do |
|---|---|---|
| Hub location | Determines first-hop reliability | Keep it central and away from interference |
| Powered repeaters | Battery locks usually do not repeat | Add plugs/modules near lock paths |
| Wall material | Concrete, brick, and metal cut signal | Measure instead of guessing |
| Protocol | Z-Wave, Zigbee, and Thread behave differently | Match protocol to building and hub |
| Door usage | Heavy use increases retries and battery load | Plan stronger signal for busy doors |
| Recovery path | Locks must work during outages | Keep local codes and backup access |

## Repeater Placement Rules

Place repeaters between the hub and the lock, not behind the lock or at random outlets. For exterior doors, the best repeater may be an interior plug near the entry, a powered module in a nearby room, or a hub closer to the door path.

After adding repeaters, allow the mesh to rebuild if your platform requires it, then test lock status and commands multiple times.

## Protocol Differences

Z-Wave often works well through walls because it uses sub-GHz frequencies. Zigbee and Thread use 2.4 GHz, so they can face more Wi-Fi and appliance interference. Thread has a Matter-forward path, while Zigbee has a mature hub and repeater ecosystem.

The right protocol depends on the building, not a generic range number.

## Battery Impact

Weak mesh links cause retries. Retries wake the lock, delay commands, and reduce battery life. If batteries die faster than expected, check signal and door alignment before blaming the brand.

For Wi-Fi locks, read [Wi-Fi Smart Lock Battery Drain](/articles/protocols/wifi-smart-lock-battery-drain). For mesh locks, verify repeaters and hub placement first.

## Rental and Multifamily Notes

Do not standardize a rental or multifamily fleet from a desk test. Pilot doors on different floors, at corridor ends, near elevators, and behind metal fire doors. Record battery life, command latency, and support tickets before scaling.
