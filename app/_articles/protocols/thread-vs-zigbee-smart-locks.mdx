## Quick Answer

Choose Thread when Matter compatibility, IP-native networking, and future ecosystem flexibility matter most. Choose Zigbee when you want a mature low-cost mesh with broad hub support and a larger installed base of repeaters and devices.

Both use 2.4 GHz, so walls, metal doors, Wi-Fi congestion, and hub placement still matter. Validate the path with the [Signal Strength Calculator](/calculators/signal-strength).

## Thread vs Zigbee Comparison

| Decision area | Thread smart locks | Zigbee smart locks |
|---|---|---|
| Network type | IP-based low-power mesh | IEEE 802.15.4 low-power mesh |
| Smart-home path | Usually Matter-focused | Mature hub and automation ecosystems |
| Hub need | Thread border router plus controller | Zigbee coordinator or hub |
| Battery profile | Strong when implemented well | Strong and proven in many products |
| Ecosystem maturity | Newer for locks | More mature device availability |
| Best fit | Future-facing Apple/Google/Alexa/SmartThings homes | Existing Zigbee homes, Home Assistant, and budget mesh |

## Hub and Controller Requirements

Thread needs a border router to connect the Thread mesh to your home network. Zigbee needs a coordinator or hub such as SmartThings, Hubitat, Home Assistant with a Zigbee radio, or selected Echo devices.

For buyers, the practical question is not just "which protocol is better?" It is "which controller will manage the lock, expose the features, and be supportable when something fails?"

## Range and Channel Planning

Thread and Zigbee both use 2.4 GHz. That means they can share many of the same interference problems: dense Wi-Fi, concrete, metal doors, appliances, and poor hub placement.

Thread may self-heal well in newer Matter homes, while Zigbee benefits from many existing powered plugs, bulbs, and repeaters. Either protocol can fail if there is no powered node between the controller and the lock.

## When to Choose Each

| Scenario | Better starting point |
|---|---|
| Apple-first home with border routers | Thread |
| Existing Zigbee smart home | Zigbee |
| Home Assistant user with Zigbee coordinator | Zigbee |
| Mixed Apple/Google/Alexa household | Thread through Matter |
| Budget rental upgrade | Zigbee if the hub is already owned |
| Long-term platform flexibility | Thread or Matter-over-Thread |

## Buyer Mistakes

- Assuming Thread and Matter are the same thing.
- Buying a Zigbee lock before confirming hub support for door locks.
- Depending on battery devices as repeaters.
- Ignoring 2.4 GHz congestion because the protocol is "mesh."
- Choosing a protocol before checking door fit and guest-code needs.
