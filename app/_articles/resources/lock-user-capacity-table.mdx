## Memory Limits

| Lock Grade / Type | Typical Capacity | Notes |
| :--- | :--- | :--- |
| **Residential (Grade 3)** | 20 - 50 codes | Basic chipsets (e.g., Kwikset Halo) |
| **Prosumer (Grade 2)** | 100 - 250 codes | Schlage Encode, Yale Assure |
| **Commercial (Grade 1)** | 500 - 2,000 codes | Alarm Lock Trilogy, Schlage CO |
| **Cloud-Managed** | Unlimited* | *Stored in cloud, synced in batches to lock |

### Key Takeaways
*   **The "Rotational" Limit**: Even if a lock holds 250 codes, scrolling through them on a keypad for management is a nightmare. Use an App or Web dashboard for anything over 10 users.
