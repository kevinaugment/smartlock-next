## Installation Time Reference

| Lock Type | Professional Install (Min) | DIY Install (Min) | Complexity |
| :--- | :--- | :--- | :--- |
| **Retrofit (August/SwitchBot)** | 10-15 | 15-30 | Low |
| **Deadbolt Replacement** | 20-30 | 45-60 | Medium |
| **Mortise Lock** | 45-60 | 90-120 | High |
| **Fresh Install (Drilling)** | 30-45 | 60-90 | High |
| **Wired Electric Strike** | 60-90 | Not Recommended | Very High |

### Factors Affecting Time
*   **Door Condition**: Misaligned doors can double install time.
*   **Material**: Metal doors require special drill bits and time.
*   **Access**: Getting power to the door (for wired locks) is the biggest variable.
