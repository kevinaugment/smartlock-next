### Protocol Recommendation

**Best for Airbnb: WiFi or Zigbee**

| Protocol | Pros | Cons | Best For |
|----------|------|------|----------|
| **WiFi** | ✅ No hub<br>✅ Easy setup<br>✅ Cloud access | ❌ 3-4 month battery<br>❌ Internet dependent | Single property, frequent turnover |
| **Zigbee** | ✅ 12+ month battery<br>✅ Reliable<br>✅ Offline capable | ❌ Need hub<br>❌ More complex | Multiple properties, less tech-savvy |

- Managing 5+ properties (battery costs add up)
- Have smart home ecosystem already
- Want maximum reliability
- Comfortable with hubs

## Operational Best Practices

### Code Management Strategy

**Single code vs unique codes:**

| Strategy | Pros | Cons | Best For |
|----------|------|------|----------|
| **Unique per guest** | ✅ Audit trail<br>✅ Security<br>✅ Professional | ❌ More management<br>❌ Potential PMS integration needed | Most hosts |
| **Rotating weekly** | ✅ Simple<br>✅ Less management | ❌ Less security<br>❌ No audit trail | Very small scale |
| **Same code always** | ✅ Ultra simple | ❌ Very insecure<br>❌ No accountability | ⚠️ Not recommended |

**Recommended:** Unique code per reservation

**Code format:**
- 4-6 digits (balance security and memorability)
- Avoid: 1234, 0000, repeating patterns
- Avoid: Dates, addresses
- Use lock's random generation

### Battery Management

**Prevent battery lockouts:**

✅ **Set calendar reminders**
- WiFi locks: Every 3 months
- Zigbee/Z-Wave: Every 12 months

✅ **Monitor battery level**
- Check app weekly
- Replace at 30% (not 10%)
- Keep spare batteries on-site

✅ **Guest arrival timing**
- Never replace batteries on turnover day
- Do it 1-2 days before next guest

✅ **Emergency backup**
- Physical key hidden securely
- 9V battery emergency power (if supported)
- Local contact with spare key

### Maintenance Schedule

**Monthly:**
- Check battery level
- Test lock operation (lock/unlock)
- Clean keypad (fingerprints, dirt)
- Verify codes are expiring correctly

**Quarterly:**
- Replace WiFi lock batteries
- Lubricate lock mechanism
- Tighten installation screws
- Test physical key backup

**Annually:**
- Replace Zigbee/Z-Wave batteries
- Deep clean lock exterior
- Check door alignment
- Update firmware if available

## Common Guest Issues & Solutions

### Issue 1: Guest Can't Get Code to Work

**Troubleshooting script for guests:**

"Try these steps:
1. ✅ Enter code slowly (1 second between digits)
2. ✅ Press # or ✓ after code
3. ✅ Turn handle immediately after beep
4. ✅ Verify you're at correct door
5. ✅ Check code start time (4pm check-in)"

**Remote diagnostics:**
1. Check if code is active in app
2. Verify dates/times correct
3. Check battery level
4. Send test unlock command
5. Regenerate code if needed

**Emergency backup:**
- Physical key location
- Neighbor with backup key
- Your arrival time if needed

### Issue 2: Door Won't Lock

**Common causes:**
- ⚠️ Door not fully closed
- ⚠️ Strike plate misaligned
- ⚠️ Deadbolt binding
- ⚠️ Low battery

**Guest instructions:**
"Push door firmly closed until you hear lock engage. If still not locking, try these:
1. Close door harder (may need firm push)
2. Lift door handle while closing
3. Check nothing is blocking door frame
4. Call host if persists"

### Issue 3: Guest Locked Out

**Prevention:**
- Auto-lock enabled
- Codes don't expire until 11am checkout day
- Physical key backup
- Emergency contact clearly stated

**Response protocol:**
1. Verify guest identity
2. Generate temporary emergency code
3. Send via text/call immediately
4. Guide through entry
5. Follow up to prevent recurrence

### Guest Privacy vs Security

**What to monitor:**
- ✅ Entry/exit times (reasonable for property protection)
- ✅ Failed code attempts (security concern)
- ✅ Battery status (operational need)

**What NOT to monitor:**
- ❌ Real-time location tracking
- ❌ Inside activities
- ❌ Personal conversations

**Disclosure:**
- State clearly: "Lock logs entry/exit times"
- Mention in listing and house rules

### Preventing Unauthorized Access

**Security measures:**

✅ **Unique codes per guest** (no reuse)  
✅ **Time-limited codes** (expire at checkout)  
✅ **Audit logging** (review weekly)  
✅ **Failed attempt alerts** (notify immediately)

**After bad guest:**
- ✅ Delete their code immediately
- ✅ Change master code if they saw it
- ✅ Review entry logs
- ✅ Consider re-keying if physical key was provided

## Regional Considerations

### Climate-Specific Challenges

**Cold weather (<0°C / 32°F) considerations:**

```
Arctic/Cold Climate Smart Lock Strategy:

Challenge #1: Battery performance degradation
├─ Alkaline batteries: 50-70% capacity loss <0°C
├─ Solution: Energizer Ultimate Lithium (rated to -40°C)
├─ Cost: $12/4-pack vs $4 alkaline
└─ Benefit: No mid-winter failures, consistent performance

Challenge #2: Lock mechanism freezing
├─ Issue: Moisture freezes in deadbolt, lock jams
├─ Prevention: Silicone spray (NOT WD-40) before winter
├─ Install: Weather-rated lock (IP65 rating minimum)
└─ Check: Door seal prevents moisture intrusion

Challenge #3: Guest unfamiliarity with frozen locks
├─ Provide: De-icer spray or lock de-icing instructions
├─ Alternative: Heated keypad models (rare, expensive)
├─ Backup: Always have physical key access nearby
└─ Communication: Winter check-in notes

Cold Climate Lock Recommendations:
├─ Yale Assure Lock 2 (tested to -30°C)
├─ Schlage Encode Plus (commercial cold rating)
└─ Avoid: Budget WiFi locks (often fail <-10°C)
```

**Hot/humid weather (>30°C / 86°F + high humidity):**

```
Tropical/Humid Climate Considerations:

Challenge #1: Accelerated battery corrosion
├─ Alkaline leak risk: 3× higher in humid environment
├─ Solution: Lithium batteries (corrosion-resistant)
├─ Check: Monthly battery compartment inspection
└─ Replace: At 40% (not 20%) to prevent leakage

Challenge #2: Electronic component failure
├─ Humidity damages circuit boards
├─ Solution: IP65+ rated locks (sealed electronics)
├─ Avoid: Budget locks with poor sealing
└─ Install: Covered entrance (porch/overhang) if possible

Challenge #3: UV degradation of plastic keypads
├─ Issue: Direct sunlight fades numbers, cracks plastic
├─ Solution: Metal keypad models
├─ Or: Apply UV-protective film
└─ Replace: Every 3-4 years if sun-exposed

Humid Climate Lock Recommendations:
├─ August Pro (sealed design, proven in Florida)
├─ Schlage Encode (weather-resistant build)
└─ Avoid: Wyze Lock (reports of humidity issues)
```
