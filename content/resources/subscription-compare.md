## 5-Year Cost Breakdown (100 Units)

| Cost Component | Cloud SaaS (e.g., SmartRent, Latch) | Local / Self-Hosted (e.g., Zigbee + HA) |
| :--- | :--- | :--- |
| **Hardware Upfront** | $25,000 | $30,000 (Hubs needed) |
| **Setup Labor** | $2,000 (Plug & Play) | $5,000 (Configuration) |
| **Annual Subscription** | $10,000 ($8/unit/mo) | $0 - $500 (Maintenance) |
| **5-Year Total** | **$77,000** | **$37,500** |

### The Trade-off
*   **Local**: Saves 50%+ money, requires IT skill, privacy focused, no recurring fees.
*   **Cloud**: Costs double, requires 0 skill, managed upgrades, vendor lock-in.

## Justifying the Subscription

Don't pay a subscription just to "unlock with phone". Pay for features that save expensive labor:

1.  **PMS Integration**: Automatically sending codes to guests (Airbnb/vrbo) saves ~5 mins per booking. At 100 bookings/year, that's 8 hours saved per lock.
2.  **Audit Trails**: Cloud logs provide legal defense for "unauthorized entry" claims.
3.  **Staff Management**: Revoking a housekeeper's access across 50 properties instantly vs visiting 50 doors.
4.  **Battery Monitoring**: Alerting maintenance *before* a lock dies saves $150 emergency lockout visits.

If a subscription doesn't do these things, **don't pay for it**.
